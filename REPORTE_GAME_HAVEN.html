1. Definición

¿Qué es Game Haven?

Game Haven es una aplicación de escritorio desarrollada en C# con .NET Framework 4.8, diseñada específicamente para gestionar y organizar una biblioteca digital personal de videojuegos. Permite a usuarios registrar, clasificar, buscar y exportar información sobre sus juegos de múltiples plataformas.

Propósito Principal

Game Haven resuelve la necesidad común de jugadores y coleccionistas de mantener un registro organizado y accesible de su biblioteca personal de videojuegos. Proporciona control total sobre la información de juegos, estados de progreso, calificaciones personales y notas adicionales, todo sin depender de conexión a internet.

✨ Capacidades Clave:
  • Registrar videojuegos de diversas plataformas
  • Gestionar información completa de cada juego
  • Realizar búsquedas y filtrados avanzados
  • Exportar datos en formatos estándar (JSON, CSV)
  • Acceder a información completamente offline

2. Características Principales

🎮 Gestión de Biblioteca

Agregar, editar y eliminar juegos con información completa de forma rápida e intuitiva.

🔍 Búsqueda y Filtrado Avanzado

  • Buscar por título del juego
  • Filtrar por plataforma (PC, PS4, PS5, Xbox, Nintendo Switch, etc.)
  • Filtrar por género (Acción, RPG, Aventura, Estrategia, etc.)
  • Filtrar por estado (Pendiente, Jugando, Completado, etc.)
  • Mostrar solo juegos favoritos

📊 Información Detallada

Cada juego registra:

  • Título y plataforma
  • Género y año de lanzamiento
  • Desarrollador
  • Estado actual del juego
  • Calificación personal (0-10)
  • Horas jugadas
  • Marcador de favoritos
  • Notas personales
  • Fechas de registro y modificación

📁 Almacenamiento Local

Base de datos local en formato JSON sin conexión a internet requerida.

📤 Exportación de Datos

Exportar a JSON (estructura completa) o CSV (compatible con Excel).

🖼️ Interfaz Intuitiva

Diseño amigable con ventanas modales y no modales para facilitar la experiencia del usuario.

4. Ejemplo: Flujo de Funcionamiento

Caso de Uso: Carlos Organiza su Biblioteca

Carlos es un coleccionista de videojuegos con más de 100 títulos en diferentes plataformas. Quiere organizar su biblioteca y llevar un registro de su progreso.

Paso 1: Iniciar Aplicación

Carlos abre Visual Studio y ejecuta Game Haven. La aplicación:

  1. Inicializa DatabaseManager
  2. Carga datos existentes desde GameLibrary.json
  3. Inicializa controles de interfaz
  4. Muestra ventana principal vacía

Paso 2: Agregar Primer Juego

Carlos presiona "➕ Agregar" y completa el formulario con detalles de "The Witcher 3":

Título: The Witcher 3 Plataforma: PC Género: RPG Developer: CD Projekt Red Año: 2015 Estado: Completado Calificación: 9.5 Horas: 125 Favorito: ☑ Notas: Juego extraordinario...

Paso 3: Buscar Juegos

Carlos presiona "🔍 Buscar" para encontrar todos sus juegos RPG que son favoritos. El sistema filtra en tiempo real y muestra resultados coincidentes.

Paso 4: Editar Información

Carlos selecciona un juego y presiona "✏️ Editar" para actualizar su estado o notas.

Paso 5: Exportar Datos

Carlos presiona "📥 Exportar" para generar un archivo CSV de su biblioteca completa.

💡 Nota: Todos los datos se guardan automáticamente en GameLibrary.json después de cada operación.
