APLICACIÓN DESARROLLADA: GAME HAVEN
═════════════════════════════════════════════════════════════

🎮 DESCRIPCIÓN:
Aplicación de escritorio profesional para gestionar una biblioteca 
personal de videojuegos, desarrollada en C# con .NET Framework 4.8 
usando Windows Forms.

EJEMPLO DE USO
═════════════════════════════════════════════════════════════

PASO 1: Iniciar Aplicación
  1. Ejecutar GameLibrary.exe
  2. Se abre ventana principal con lista vacía
  3. DatabaseManager carga datos de GameLibrary.json

PASO 2: Agregar Juego
  1. Presionar botón "➕ Agregar"
  2. Se abre formulario modal AddGameForm
  3. Completar datos del juego
  4. Presionar "Guardar"
  5. Juego se agrega y lista se actualiza

PASO 3: Ver Lista
  1. DataGridView muestra todos los juegos
  2. Ver nombre, plataforma, estado, favorito, etc.
  3. Scroll para ver más juegos

PASO 4: Buscar/Filtrar
  1. Presionar botón "🔍 Buscar"
  2. Se abre formulario modal SearchFilterForm
  3. Ingresar criterios (texto, plataforma, estado)
  4. Presionar "🔍 Buscar"
  5. Tabla se actualiza con resultados

PASO 5: Editar Juego
  1. Seleccionar juego en tabla
  2. Presionar botón "✏️ Editar"
  3. Se abre formulario modal EditGameForm
  4. Modificar campos deseados
  5. Presionar "Guardar"

PASO 6: Eliminar Juego
  1. Seleccionar juego en tabla
  2. Presionar botón "🗑️ Eliminar"
  3. Confirmar eliminación
  4. Juego se remueve de la tabla

PASO 7: Exportar Datos
  1. Presionar botón "📥 Exportar"
  2. Se abre formulario modal ExportForm
  3. Seleccionar qué exportar (todos/favoritos/filtro)
  4. Seleccionar formato (JSON/CSV)
  5. Presionar "Exportar"
  6. Seleccionar ubicación y guardar archivo

CÓMO USAR EL PROYECTO
