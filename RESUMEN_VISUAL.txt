🚀 CÓMO USAR:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

INSTALACIÓN:
1. git clone https://github.com/danielsosadev-hub/GameLibrary.git
2. cd GameLibrary
3. start GameLibrary.slnx (Visual Studio)

COMPILACIÓN:
1. Ctrl + Shift + B (Visual Studio)
2. O: dotnet build

EJECUCIÓN:
1. F5 (Visual Studio)
2. O: dotnet run
3. O: Ejecutar bin\Debug\GameLibrary.exe

PRIMERA VEZ:
1. Se crea GameLibrary.json automáticamente
2. Presiona "Agregar" para crear el primer juego
3. Completa los campos
4. Presiona "Guardar"
5. ¡Listo!
